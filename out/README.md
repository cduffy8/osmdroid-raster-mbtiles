# Converted maps

Completed raster MBTiles files and per-run JSON reports are written here by default. Nested input paths are mirrored. A `.partial` file is unfinished output, never a completed map.

Existing files are not overwritten. Review the report for `converted`, `failed`, `skipped_existing`, `cancelled`, and `not_run` results.

Generated files in this folder are ignored by Git.
